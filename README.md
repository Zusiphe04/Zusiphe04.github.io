## 📍 Project Overview: LocalPro

**LocalPro** is a South Africa-focused digital directory platform designed to connect local service providers (plumbers, electricians, builders, solar installers, tutors, and handymen) with clients. It features freemium and paid subscription tiers (R0 Basic vs R299/month Pro tier), interactive directory search, a 5-step guided quote request wizard, a provider lead dashboard, and verified customer review workflows.

## 🛠️ Technology Stack

### Application & Interface Development
- **React & JavaScript:** Component-based user interface, interactive quote wizard, and responsive navigation.
- **Tailwind CSS:** Modern design system optimized for desktop and mobile layouts.
- **Next.js / Node.js:** Application routing, API endpoints, and data management.

### Data & Services
- **Database Management:** Structured storage for provider profiles, listings, leads, and customer reviews.
- **Payment Gateway Integration:** Subscription workflows for the R299/month Pro tier via PayFast, SnapScan QR, and direct EFT.
- **Version Control & Hosting:** Git, GitHub, VS Code, and GitHub Pages.
